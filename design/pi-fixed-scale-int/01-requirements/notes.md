# pi-fixed-scale-int · 非功能 / 未决 / 澄清（L1）

## 非功能

- 默认基础整数运算不引入高精度数学依赖；序列化及高精度数学分别按需启用。来源：原有零默认依赖诉求与用户随后明确的纯 Rust 可选数学依赖要求。
- 常规整数乘除使用可容纳中间积的宽整数；指数、对数要求无 f64 中间计算，以可验证的上下界确认严格结果。来源：用户关于两档精度及纯 Rust 高精度实现的确认。
- 普通数学结果至多偏离正确舍入 1 raw，严格结果必须正确舍入或明确报精度不足；没有吞吐量指标或已验证的性能倍数。来源：用户对误差与双方法命名的确认。

## 未决清单

无待用户决定的公开行为。已在 L5 核对依赖的正确舍入与实际定向规则，在 L7 补齐正常有限路径的区间组合证明；异常区间保护与错误传播仍待实现验收，不能把文档证明或旧测试通过误记成实现全部满足前提。

## 澄清记录

- 分母：用户后续改定为任意正 u32 分母，指定的九个分母是便捷选项；零分母在公开操作使用时编译失败。
- 运算：加减和比较保持同类型同分母；乘除可混合分母、整数类型及原生整数，输出沿用左侧类型和分母。
- 输入与输出：原始计数、完整整数、十进制文本与有限浮点；支持十进制展示和可选序列化；不含正负类别隐式互转。
- 失败：普通结果超界返回错误，饱和结果超界夹边界，除零始终返回错误。
- 舍入：默认向零截断，另有半值远离零的四舍五入方法。
- 零分母公开操作编译期拒绝；math、serde、fory 按需增加各自依赖，不误述为零第三方依赖。
- 乘除正负半值及非零除数的饱和边界验收系 L9 独立轻审后补。
- 数学方法集合：e^x、2^x、自然/2/10/指定底数对数及整数幂；普通版与严格版分名；严格不可证明时返回精度不足，普通相差最多一个 raw。来源：本次对话确认。
- 最终范围以正确舍入后的 raw 为准：无符号微小负真值允许舍入为零；底层 NaN/错误/无证明无穷/倒置区间报 ComputationFailed；对数商分母跨零或负幂倒数前端点为零先升精度，耗尽报 PrecisionExhausted。来源：本轮用户明确裁定。
