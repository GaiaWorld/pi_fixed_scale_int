# pi-fixed-scale-int · 非功能 / 未决 / 澄清（L1）

## 非功能

- 运行时零第三方依赖。来源：用户澄清。
- 以 128 位整数进行中间计算。来源：用户澄清及分母范围调整。
- 性能指标无：用户未提出指标或负载。

## 未决清单

无公开行为待决；公开操作使用零分母时的编译期拒绝方式留待技术设计验证。

## 澄清记录

- 分母：用户后续改定为任意正 u32 分母，指定的九个分母是便捷选项；零分母在公开操作使用时编译失败。
- 运算：加减乘除、比较及转换；同分母直接运算，跨分母须显式转换。
- 输入与输出：原始计数和完整整数双入口；换分母及截断或舍入整数输出；不含正负类别互转。
- 失败：普通结果超界返回错误，饱和结果超界夹边界，除零始终返回错误。
- 舍入：默认向零截断，另有半值远离零的四舍五入方法。
- 零分母编译期拒绝；零运行时第三方依赖。
- 乘除正负半值及非零除数的饱和边界验收系 L9 独立轻审后补。
