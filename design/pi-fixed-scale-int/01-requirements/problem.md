# pi-fixed-scale-int · 问题与范围（L1）

## 问题

使用者需要可靠地输入、展示和计算有明确单位精度的数值，既能处理常规运算，也能按可区分的精度保证得到指数、对数和整数次幂结果；结果的舍入、失败原因和可表示范围必须可预测，失败不能悄悄改变原值。

## 不在范围内

- 跨分母直接加减或比较：保留原有类型边界，调用者须显式转换后再操作；跨分母乘除则按左值确定结果精度。
- 正负类别之间隐式互转：舍入后仍为负的原始计数不能由无符号类别表示，须显式选择目标类别；微小负真值正确舍入为零不视为类别互转。
- 无限范围或任意精度的结果存储：结果仍受两类 64 位原始计数约束；更大计算只用于中间值和误差界。
- 超过 u32::MAX 的分母与单个值运行期间自动改变分母：固定分母是类型的一部分，改变分母须显式转换。
