# pi-fixed-scale-int · 触达模块（L5 返工）

| 模块 | 职责 | 隐藏的唯一易变决定 |
|---|---|---|
| 公开数值层 `src/lib.rs` | 固定分母值的可见类型、操作入口与错误边界 | 对调用者开放哪些输入与操作以及结果类型/分母 |
| 基础计算 `src/fixed_inner.rs` | 原始计数、宽整数算术、比例、文本转换和十进制显示 | 固定分母数值如何无浮点地算术、缩放与显示 |
| 可选高精度计算 `src/math_inner.rs` | 指数/对数/整数幂的区间求值、量化与精度上限 | 两档模式如何界定及确认结果精度 |
| 可选外部编解码 serde/fory | 按 feature 派生原始计数序列化能力 | 与外部协议的编解码适配规则随依赖而变 |

数值类型只有 64 位原始计数与编译期固定分母；数学计算内部可用更高精度，但结果不扩大底层表示。对象不变，所有失败均不修改调用者持有的源值。未涉及其他项目模块。
