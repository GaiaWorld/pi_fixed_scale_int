# 登记分册：词汇表

## 词汇

| 术语 | 定义 | 出处 |
|---|---|---|
| 分母 | 数值单位被划分的固定正 u32 份数 | L1 需求 |
| 原始计数 | 以分母为单位的整数份数 | L1 需求 |
| 完整整数 | 没有小数部分的数值输入或输出 | L1 需求 |
| 饱和 | 超界时夹到目标类别可表示的边界 | L1 需求 |
| 向零截断 | 舍弃不能表示的剩余部分 | L1 需求 |
| 半值远离零 | 恰好半值时朝绝对值增大方向舍入 | L1 需求 |
| 正确舍入 | 按数学精确结果半值远离零所得的唯一原始计数；未能证明时不返回猜测值 | 用户精度澄清 |
| 普通精度 | 计算结果相对正确舍入的原始计数偏差最多一单位 | 用户两档精度澄清 |
| 精度不足 | 在规定计算上限内无法证明普通或严格档的相应误差保证时返回的错误 | 用户严格方法澄清 |
| raw | 原始计数的英文别名，数值等于 raw 除以分母 | 数值方法及数学需求 |
| 严格档 | 仅在正确舍入的整数 raw 可证明时返回数值的数学方法档位 | 用户两档精度澄清 |
| 封闭上下界 | 对数学真值始终满足下界≤真值≤上界的区间不变量 | L7 数学调用链 |
| 端点量化 | 将区间两端分别按半值远离零变为原始计数，以判定结果误差及正确舍入 | L7 数学调用链 |
| PrecisionExhausted | 精度上限用尽或区间不能证明目标档位结果时返回的错误变体 | math 错误合同 |
